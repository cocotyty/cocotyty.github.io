# 狂飙公路 TURBO HIGHWAY

3D 无尽公路赛车游戏 — 纯浏览器运行,移动端 / 桌面双端横屏可玩。

**在线游玩**: [cocotyty.github.io/race/](https://cocotyty.github.io/race/)

## 玩法

一条永无尽头的双向公路,车流却不怎么靠谱:

- **6 种座驾任选开局**:小汽车 / 警车(爆闪灯条)/ 消防车 / 大卡车 / 赛博皮卡 / GT 跑车,
  极速、加速、操控、耐久各有取舍
- **疯狂车流**:同向车会突然别车、急刹挑衅;对向车流高速逼近;**逆行者** 250m 后解锁,
  顶着你的车道迎面冲来(HUD 有 ⚠ 预警)
- **马路危险分子**:行人随机横穿(被撞会卡通飞起)、自行车蛇形占道、摩托车高速摇摆穿梭
- **道具即时生效**:🔧 修理 +35HP · 🛡 护盾 5s · ⚡ 涡轮 4s(期间可撞飞一切)· 🪙 金币收集
- **无尽纪录**:血条归零结算,最长里程存 localStorage,分全局与单车最佳
- **昼夜循环**:每 10km 一天,黄昏 → 深夜(路灯/楼窗/车灯点亮)→ 黎明;城市 / 郊区 / 乡野
  每 1km 轮换,两侧建筑、房屋、树木、广告牌、龙门架随机生成
- **真实弯道**:四重正弦中心线,连续 S 弯 + 大半径长弯;高速过弯有离心甩出,
  需打方向修正,车身随之侧倾

## 操作

| | 桌面 | 移动端 |
|---|---|---|
| 转向 | ← → / A D | 底部 ◀ ▶ 大按钮 |
| 油门(超过巡航) | ↑ / W | ⚡ 按钮 |
| 刹车 | ↓ / S | 🛑 按钮 |
| 暂停 | Esc / P | ❚❚ 按钮 |

竖屏时提示旋转设备;键盘 Enter 可快速开局/重开。

## 技术

- **零构建**:Three.js r128(CDN,jsdelivr)+ 4 个原生 JS 文件,无打包、无 npm
- **路空间模拟**:所有实体在 (s, l) 道路坐标系中模拟,渲染时经中心线函数
  `cx(s)`(四重正弦弯道,含曲率 `d2cx(s)` 驱动离心力)映射到世界坐标,天然规避浮点漂移
- **几何条带道路**:路面/路肩/护栏均为每帧重建顶点的 BufferGeometry 条带,
  护栏随城市区域权重升起/沉没
- **对象池**:14 车 + 4 摩托 + 3 自行车 + 8 行人 + 56 粒子 + 景物 9 类全部池化复用
- **Canvas 程序纹理**:沥青标线 / 楼房立面(含夜间发光 emissiveMap)/ 广告牌 / 龙门架
- **WebAudio 合成音效**:引擎双振荡器随速变调、碰撞噪声、道具音,无音频文件
- **性能自适应**:帧率过低自动降 pixelRatio; shadows 1024 + 距离雾裁剪
