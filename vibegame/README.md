# STEEL VANGUARD · 钢铁先锋

一款魂斗罗 × 合金弹风格的横版跑打（Run & Gun）网页游戏。纯键盘操作，支持全屏，**双击 `index.html` 即可离线游玩**，无需安装任何东西。

> 2087 年，钢铁军团占领了大陆。你是先锋队最后一名突击队员。
> 三次任务：丛林抢滩 → 废墟市区 → 攻入要塞核心，终结这场战争。

## 怎么玩

直接双击打开 `index.html`（或拖进任意现代浏览器）。
推荐全屏：游戏内按 **F**。

## 📱 手机版

同一份代码自动支持触屏（检测到触屏设备即显示虚拟手柄，桌面不受影响）：

- **左侧圆形方向键**：拇指滑动换向；按住 ▲/▼ 朝上/下瞄准
- **右侧动作键**：FIRE（大，按住连发）/ JUMP / NADE
- **右上角系统键**：II 暂停 · M 静音 · FS 全屏
- 菜单画面**点按屏幕**即确认；竖屏时画面在上、手柄在下；横屏手柄半透明覆盖两下角
- 切后台自动暂停；适配刘海屏安全区；已禁用双击缩放/长按菜单

手机上打开方式：
1. **同一 WiFi**：手机浏览器访问 `http://<电脑IP>:8642`（先在电脑上运行 `node .serve.js`；电脑 IP 用 `ipconfig` 查 IPv4）
2. **离线**：把整个 `VibeGame` 文件夹传到手机，用浏览器打开 `index.html`
3. 推荐"添加到主屏幕"当 App 用；横屏 + FS 全屏体验最佳

桌面浏览器想用触控按钮：地址加 `?touch=1`。

## 🎮 微信小游戏版

`wxgame/` 目录是微信小游戏版（与网页版同源码自动打包）：

- **玩法**：打开就是横屏全屏 + Canvas 虚拟手柄（方向垫可滑动换向 + FIRE/JUMP/NADE + 暂停/静音），菜单点屏幕确认
- **适配**：无 DOM 环境（平台垫片）、WebAudio→`wx.createWebAudioContext`、最高分→`wx storage`、切后台自动暂停
- **构建**：改了 `js/` 源码后运行 `node build-wx.js` 重新生成 `wxgame/game.js`

**怎么在手机上玩（三步）：**
1. 下载安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版）
2. 导入项目 → 目录选 `wxgame/` → AppID 选"测试号/游客模式" → 模拟器立即能玩（横屏）
3. 想在真机上玩：工具栏"预览"扫码（游客模式支持）；或到 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册自己的小程序 AppID 填入 `project.config.json`

> ⚠️ 微信政策：**个人主体不能正式发布"游戏类目"**（需企业资质+软著）。自己玩/朋友体验用上面的开发版/体验版完全没问题。

## 游戏规则

- **4 点生命 · 3 条命**：受击扣血并短暂无敌；命耗尽可 Continue（保留分数）重打当前关。
- **检查点**：每关两面红旗，触碰后死亡从此复活。
- **武器**：步枪 R（默认）→ 散弹 S（三向）/ 机枪 H（高射速），击碎木箱掉落补给；死亡回到步枪。
- **补给**：💚医疗包 +1 HP ｜ 💣手雷包 +3 ｜ 💎宝石 +500 分 ｜ 生命十字 +1 命（Boss 掉落）。
- **得分**：每 10000 分奖励 1 命，之后每 15000 分再加命；最高分存在本地。
- **关卡通关**：击杀关底 Boss 自动结算（剩余命 ×1000 + 剩余 HP ×250 加分）。

## 技术说明

- 纯原生 HTML5 Canvas + JavaScript，**零依赖、零外部资源**，单机离线可玩。
- 所有像素画（角色 3×5 字体、瓦片、Boss）、音效与芯片音乐全部由代码程序化生成（WebAudio 合成），可自由使用与修改。
- 内部分辨率 480×270 像素风渲染，自适应缩放 + CRT 扫描线效果。
- 固定 60fps 时间步长物理；单向平台、土狼时间、跳跃缓冲齐全。

