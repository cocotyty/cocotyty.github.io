# 魂火守卫 SOULFIRE DEFENSE

像素暗黑风塔防网页游戏。夜幕下的怪物大军步步进逼,建造并升级防御塔,守住最后的魂火。

## 运行方式

无需构建、无需依赖,直接用浏览器打开 `index.html` 即可。

(可选)本地服务器方式:

```bash
cd td
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 玩法

- 点击底部商店选择塔 → 点击地图上**路径外的任意空格**自由建造
  - 桌面(鼠标):点击直接建造,悬停显示射程预览(金色=可建,红色=不可建)
  - 移动端(触屏):**两步确认**——首次点击格子出现预览与"✓建造/✕取消"面板,再点同格或按 ✓ 才扣钱建造,防误触
- 点击已建造的塔 → 升级 / 出售
- 点击 HUD 的「⛶」进入全屏:安卓会尝试锁定横屏;不支持的环境(如 iPhone)提示旋转设备
- **移动端强制横屏**(借鉴 race 游戏):触屏设备竖屏时显示"请旋转设备"遮罩,旋转后即可游玩;桌面端不受影响
- 点击 HUD 的「下一波」提前召唤敌人,剩余秒数换金币奖励
- 怪物抵达魂火会扣生命,生命归零则失败;撑过全部波次即通关
- 通关按魂火剩余生命结算 ★☆☆(满血 3 星),并解锁下一关
- 支持 ×2 游戏速度、暂停、音效开关;进度保存在 localStorage

调试 URL 参数:`?touch` 强制触屏布局与两步建造逻辑。

## 8 种塔(各有 3 个等级)

| 塔 | 特性 |
|---|---|
| 弩楼 | 便宜的高速单体物理伤害 |
| 轰天炮 | 溅射范围物理伤害 |
| 狱炎盆 | 近距持续喷火 + 灼烧 |
| 凛冬晶塔 | 冰片减速 |
| 瘟疫釜 | 毒液持续腐蚀 |
| 风暴尖塔 | 闪电链跳跃攻击 |
| 幽界法球 | 超远射程重击 + 小溅射 |
| 诅咒图腾 | 无伤害,诅咒敌人使其承受伤害 +30%/+45%/+60% |

## 9 种怪物

行尸 / 白骨 / 血蝠 / 哀魂(物理减伤 55%)/ 尸蛛(死亡分裂幼蛛)/ 裂躯者(重甲)/ 地狱魔(自愈)/ 幼蛛 / **旧日支配者**(最终 Boss)

## 8 个关卡

外围村落 → 白骨丘 → 瘴雾沼泽 → 废弃矿坑 → 古墓大厅 → 哀嚎深渊 → 魔鬼城 → 旧日之国(最终 Boss)

难度逐关递增,新塔随进度解锁(第 2 关起逐步开放全部 8 种塔)。

## 技术

- 纯原生 HTML/CSS/JS + Canvas,零依赖,离线可玩
- 全部像素画以字符画定义(`js/data.js`),运行时生成精灵
- WebAudio 程序化合成全部音效,无音频资源
- Pointer Events 统一处理触屏与鼠标;触屏端棋盘居左、商店竖排右侧窄条,竖屏被遮罩拦截强制横屏,桌面端保持底部商店布局

## 文件结构

```
td/
├── index.html      入口
├── style.css       界面样式(暗黑像素风 UI)
└── js/
    ├── data.js     像素素材 / 塔 / 怪物 / 关卡与波次数据
    ├── audio.js    WebAudio 程序化音效
    ├── game.js     引擎:寻路、战斗、波次、特效渲染
    └── main.js     界面流程、输入、商店、存档
```
