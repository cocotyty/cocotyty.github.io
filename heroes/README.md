# 征服纪元 · Age of Conquest

致敬《魔法门之英雄无敌 III》的纯前端回合制大策略游戏。零依赖、零构建,任何静态服务器直接可玩。

## 玩法

- **目标**:占领所有敌方城镇、消灭所有敌方英雄。
- **操作**:
  - 点击英雄选中 → 点击目标显示路径 → 再点一次确认移动
  - 右键查看物件信息;WASD/方向键平移;空格切换英雄;回车结束回合
  - 触屏:点按选择,再点目标执行
- **地图**:S 44×44 ~ XL 96×96,含中立城镇、7 类矿点、野怪守卫、宝物、野外巢穴、竞技场、女巫小屋等 20+ 种物件,战争迷雾逐步揭开。
- **种族**:城堡 / 壁垒 / 塔楼 / 地狱 / 墓地,各 7 级兵种 + 专属奇迹建筑,共 42 种兵。
- **城镇**:议事厅→国会收入链、堡垒→城堡产量链、魔法行会 5 层、酒馆、市场、资源筒仓、7 级兵营,120+ 种建筑。
- **英雄**:升级四维属性 + 12 种技能(3 级)、31 件宝物、18 种战斗法术、驻军/部队交换。
- **战斗**:13×9 战场,射手/飞行/吸血/冲锋等特性,反击、等待、防御、群体魔法、召唤元素,可手动指挥或自动战斗。
- **AI**:建设排序、扩张估值、路径危险评估、集结主英雄、驻防、市场调剂、终局消耗战,5 家 AI 混战。

## 技术

- 纯 vanilla JS,无依赖无构建;引擎层(util/data/path/mapgen/battle/game/ai)无 DOM 依赖,可在 Node 中直接 require 做自动化测试。
- 存档:localStorage(`homm_save_auto`),每天开始时自动保存。
- 测试:Node 全盘 AI 对局模拟(连通性/存档回环/压力/种族平衡) + CDP 浏览器 E2E。
