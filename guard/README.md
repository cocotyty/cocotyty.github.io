# 守护小村姑 · GUARD MAIDEN

体素风(我的世界样式)**FPS × 时停塔防 × 村民护送**,纯浏览器游戏,零构建零依赖(仅 Three.js CDN)。

> 僵尸围村。你是村子最后的英雄——一边开枪,一边时停建塔,
> 护送 20 名村民穿过尸潮走进东边城市大门。
> **阵亡超过一半,村子就完了。**

## 玩法

- **FPS 战斗**:WASD + 鼠标,左键射击(Q 手雷 AOE / E 圣光治疗 / R 圣盾免伤)
- **时停建造**:按 `B` 世界冻结、俯视 2D 视角,用僵尸掉落的金币建塔;**只能建在英雄周围 26m**,俯视图只显示英雄周边
- **护送**:村民沿 ~180m 的 S 形土路逃向东边城门(地图 156×156m,10 座僵尸传送门);身边有僵尸会恐慌加速,跑太久会力竭被追上
- **计分**:村民入城数 × 100 + 剩余金币;入城 18+ 三星

## 塔(会被僵尸啃)

| 塔 | 造价 | 特性 |
|---|---|---|
| 🏹 箭塔 | 15 | 高射速单体 |
| 💥 炮塔 | 45 | 范围爆炸 |
| ❄️ 冰霜塔 | 30 | 范围减速 55% + 冻伤 |
| 🧱 木墙 | 10 | 高血量肉盾 |

拆除返还 50%。

## 僵尸

- **walker** 普通僵尸 · **runner** 疾跑者(比恐慌村民还快) · **archer** 弓箭手(远程冷箭) · **brute** 重锤 · **giant** 巨尸(每 5 波)
- 尸潮从传送门涌来,出怪点偏向队伍尾部附近(前方/侧翼截击);撞上塔会啃

## 其他

- **🤖 自动演示模式**:主菜单"自动演示"按钮让 AI 托管英雄(跟队、风筝射击、优先狙杀弓箭手、按局势放手雷圣盾圣光、自动建塔+捡金币);游戏内 `P` 随时接管/交回,`T` 切换 x1/x2/x4 模拟加速 —— 也适合当 attract 演示和快速回归测试(normal 难度观赏性最佳)
- 3 档难度(简单/普通/困难):波间隔、僵尸血量/数量、起始金币、弓箭手比例
- 左上角以主角为中心的小地图(村民绿点 / 僵尸红点 / 塔黄块 / 城门)
- 桌面指针锁定 + 移动端虚拟摇杆/按钮;音效为 WebAudio 合成,无素材
- 最佳成绩存 localStorage(`gm_best`),难度存 `gm_diff`

## 技术

`index.html` + `style.css` + `js/game.js`(单文件 ~1600 行,无构建)。
Three.js r128 CDN。所有模型为 BoxGeometry 拼装的体素小人;地形为顶点色平面 + 体素装饰。

**测试**:Playwright/MCP 实测 —— 开局/建塔/放塔/拆除/退出/胜负结算/三难度参数/弓箭手/圣盾/小地图全部通过。
