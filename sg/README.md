# 三国烽火 · 群雄割据 196

回合制三国大战略网页游戏。剧本始于建安元年(196 年):曹操新迎天子、袁绍雄踞河北、
孙策席卷江东、吕布窥伺徐州……39 城、11 势力、130 员战将,扫平群雄,一统天下。

纯原生 JS(零依赖、零构建),手机/桌面浏览器直接玩。

## 玩法

- **内政**:每城每月一道政令——开垦(增粮)、商业(增收)、征兵、训练、修城、搜索、录用在野贤才
- **军事**:出征攻打邻城(行军一月到达)、多路合击、输送兵力辎重
- **战斗**:攻城战自动演算,玩家可实时切换战术——猛攻 / 坚守 / 火攻(智将) / 伏兵(劣势兵) / 单挑(猛将)
- **人事**:俘虏劝降 / 释放 / 处决;忠诚度过低武将会叛逃
- **胜利**:占领全部 39 城

## AI 策略(重点打磨)

每个 AI 势力每月独立决策,包含多层策略:

| 层级 | 行为 |
|---|---|
| 战略 | 前线/后方城市分类,后方持续向前线输血(兵+粮+金) |
| 内政 | 按钱粮缺口选择开垦/通商/征兵,人口兵源池管理 |
| 出征 | 按"目标聚合兵力→多路合击"两阶段决策,兵力/城防/援军综合评估 |
| 性格 | 君主性格差异化:曹操激进、刘表守成(地广而骄自动收敛)、吕布莽撞 |
| 外交直觉 | 远交近攻(避打接壤最强者)、多线作战收敛、血仇三年必报、长江天险 |
| 战术 | 战斗中按武力/智力/兵力比选火攻、伏兵、单挑时机 |

平衡性经过 **60 局 × 300 月无头模拟**验证:AI 对局统一率 53%、平均 165 月统一、
曹操/孙策双雄争霸符合历史直觉、袁术/吕布/张鲁早期出局、零死锁。

## 存档

- 每月结束**自动保存**(localStorage)
- 6 个手动存档槽 + 主菜单"继续征战"
- 存档内容为完整游戏状态 JSON

### 测试

- 逻辑层与 UI 完全解耦,引擎可在 Node 中直接运行
- 平衡模拟:`node sg/test/sim.mjs 60 300`
- 回归单测:`node sg/test/regress.mjs && node sg/test/ui-regress.mjs`
- 端到端:先 `python -m http.server 8080`,再 `node sg/test/e2e.mjs`
  (CDP 驱动本机 Chrome/Edge,捕获页面异常;覆盖按钮处理链路)
- 浏览器回归:打开 `sg/?autotest=1`,17 项自动化断言(新游戏→内政→出征→
  行军→战斗 UI→攻城→结算→自动存档→读档→24 月 AI 推演),标题变为
  `AUTOTEST-PASS` 即全过
- 视觉快照:`sg/?shot=1` 导出 canvas 像素统计

### 关键数值(调参备忘)

- 经济:金 = 商业×0.9/月;粮 = 农业×760 年收(七月);兵粮 0.55/月;断粮逃兵
- 兵源:人口×400,和平城市人口 +1.5%/月
- 战力:`兵力 × (0.55+统率/240) × (0.6+士气/250) × 城防(1+城防/320)`
- 均输平准:势力内粮按驻军比例、金按城数均分(中央调度)
- 剧本加成:曹操本部兵 ×2.15(挟天子四战之地)、张鲁汉中 ×1.6(天险)
